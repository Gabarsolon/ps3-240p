# v1.3.6 - CRT Toolset: PAL 288p and live SD selection

Adds full-picture PAL 288p, explicit stock 480i/576i selection with saved boot
defaults, and the CRT Toolset name. The first four menu actions are Test 240p,
Enable 240p enforcement, Test 288p, Enable 288p enforcement.

## Changes

**PROVEN (release source):** `app/source/timing_payloads.h`, `lv1_patch.c`,
`switch_flow.c`, `plugin_lifecycle.c`, `sd_default.c`, `main.c`, `ui_layout.c`,
and `plugin/vsh_video.c` implement the following changes.

- Cover the special analog PAL timing record as well as the ordinary tables;
  retain 576 source lines with a 624-line frame.
- Use genuine VSH display calls for background correction. Reuse an unchanged
  resident helper, check occupied slots and replacement failures, and verify
  worker readiness before arming it.
- Restore stock 480i/60 Hz or 576i/50 Hz live, with 15-second picture confirmation
  and verified saved defaults through webMAN.
- Repaint after closing the PS menu so dimming/loading indicators clear without
  D-pad input.
- Rename the app/header to CRT Toolset while retaining title ID `PS240P001`.

## Install and dependencies

Reboot first to clear older resident helpers/RAM timing edits. Install
**CRT-Toolset.pkg** through normal XMB Package Manager, select AV Multi Out,
then test/enable the desired mode. Enable again after each reboot.
Remote webMAN installation intermittently froze the development console;
use the normal XMB installer.

Low-line output/enforcement requires supported CFW LV1 access and Cobra/PS3MAPI;
ordinary HEN is unsupported. The core output/helper does not require webMAN,
but saving 480i/576i boot defaults currently uses its named-key HTTP interface.
[Compatibility](https://github.com/Gabarsolon/ps3-240p/blob/v1.3.6/docs/HEN_SUPPORT.md)
and [default switching](https://github.com/Gabarsolon/ps3-240p/blob/v1.3.6/docs/SD_MODE_SWITCHING.md).
