# v1.5.0-dev14: select FP SCALE for the progressive source window

Checkpoint: 2026-11-14. Full-picture fitting remains to be tested.

**PROVEN (prior evidence):** dev13's progressive raster plus three source
window/scaler RAM edits produced visible but cropped video. See
[dev13](HD540_DEV13.md).

**PROVEN (private trace):** `0x80003bcc` writes raster field 13 to native
FP timing-generator control `0x680848`; `0x80002ca4` separately merges its
mode bits `0x300`. Stock HD field 13 has mode bits `0x100`. Source: private
4.93 binary at those addresses and `0x80038b28 + profile*56 + 52`.

**CLAIMED (independent definitions):** mode `0x100` selects CENTER and mode
zero selects SCALE. Source:
[Linux v6.12 nvreg.h](https://github.com/torvalds/linux/blob/v6.12/drivers/gpu/drm/nouveau/dispnv04/nvreg.h),
definitions `NV_PRAMDAC_FP_TG_CONTROL_MODE_CENTER` and `_MODE_SCALE`.
**INFERRED:** the previous CENTER selection could bypass the scaler despite
its enable flag and source-step edits. Clearing only the mode bits tests
that mechanism without changing the receiver-detected progressive timing.

**PROVEN (implementation):** both audited 1080i profiles now clear only
`0x300` in the final timing-control field. All other source-window, progressive
fetch, vertical raster, horizontal timing and AVI behavior remains as dev13.
This raises the transaction to twelve timing qwords plus one AVI and three
source-window code qwords. Original code is still saved at runtime and
restored before stock mode recovery. Source: `app/source/hd540_patch.c`,
`hd540_scale.c` and `plugin/vsh_hd540.c`.

**PROVEN (checks):** the host suite, 24 startup cases, twelve timing-write
failure positions and sixteen combined failure positions pass. Tests assert
that no other timing-control bits change. Private firmware code/timing
fingerprints, helper loader contract and package-member checks pass.
Protocol HD5D / `crt_hd540.v13.ready` requires the matching resident helper.

**PROVEN (artifact/deployment):**
`build/hd540/deliverables/CRT-Toolset-1.5.0-dev14.pkg`, SFO 01.63,
305280 bytes, SHA-256
`4ffba5f8e635c130ec682fba2dea336acbc6af2b54587e506962db42128dd5ab`.
App, SFO and both helpers were installed at idle XMB with known dev13 hashes,
backups and byte verification, then normal VSH restart and checked helper
load. Evidence: ignored `local_only/hd540/dev14/` deployment and auto logs.
No flash/firmware/settings installation, clocks or direct MMIO writes.
