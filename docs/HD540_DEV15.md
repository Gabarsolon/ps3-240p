# v1.5.0-dev15: native cache maintenance and scaler telemetry

Checkpoint: 2026-11-14. Experimental; correct picture geometry is not yet proven.

**PROVEN (previous console tests):** dev13 and dev14 produced visible but
cropped pictures despite the scaler instruction changes reading back in RAM.
Evidence: ignored `local_only/hd540/automatic/20261114-140559/` and
`20261114-141212/`, including saved candidate frames and recovery replies.
**INFERRED:** instruction-cache coherence or an unused scaler path could
explain that result; RAM readback alone cannot distinguish these causes.

**PROVEN (private 4.93 audit):** native AV callback descriptor `0xc0003350`
contains code address `0x8000d8ec`, TOC `0xc0012f40`, and a zero environment
word. Vtable entry `0x8003d4b8` points to that descriptor. The callback leads
to display setup through `0x8002622c` and `0x800005e4`.

**PROVEN (implementation):** the self-authored wrapper in
`plugin/hd540_cache.S` preserves the original arguments, TOC and return value.
It performs `dcbst`/`sync`/`icbi`/`isync` on the three scaler instruction
lines, calls the original callback, then records four read-only display
controls and a call counter. It makes no hardware-register stores. Sources:
`plugin/hd540_cache.S`, `app/source/hd540_cache.c` and `plugin/vsh_hd540.c`.

**PROVEN (private binary bounds):** wrapper arena `0x8003f800..0x8003f8ef`
and telemetry `0xc000de00..0xc000de1f` lie outside the declared module memory
sizes but inside their final mapped pages. Both must be zero before use.
The code segment ends at `0x8003f6c8`; data/BSS ends at `0xc000dd58`.
Source: private `sysmgr_ss.elf` program headers and live mapped-page checks.

**PROVEN (recovery design):** original timing, AVI and scaler edits are
restored first. The wrapper remains attached through stock mode setup to
flush the restored instructions. Once stock state, timing and AVI code 5
are stable, a one-second quiescence interval precedes checked descriptor
restoration and arena clearing. Changed identities or mappings are refused.
Sources: `hd540_cache_restore`, `hd540_cache_finish` and backend `at_original`.

**PROVEN (offline checks):** host tests cover all 47 combined write-failure
positions, wrapper staging/attachment failures, in-flight cleanup refusal,
retry and foreign changes. Ghidra's PowerPC64 emulator ran only the original
wrapper with a mocked callback and verified arguments, return values,
stack/TOC/nonvolatile registers, cache-operation addresses and order,
telemetry, and absence of MMIO stores. Cache operations are inspected and
skipped during ABI emulation; their physical effect remains a console test.
Sources: `tests/test_hd540_cache.c`, `tests/test_vsh_hd540.c`,
`tests/test_hd540_cache_ghidra.py`, and `tools/test_app.py --firmware`.

**PROVEN (artifact):** package
`build/hd540/deliverables/CRT-Toolset-1.5.0-dev15.pkg`, SFO 01.64, 308128
bytes, SHA-256
`1ee6344b2813924a940c5ff9b96ef3c487a54bb89240b04b8e6d9260160e22bc`.
Helper SHA-256
`26fba6e497126c46a7868d3c8164855f39a26c72603997aab03402948a12ca36`.
Protocol HD5E requires the matching resident helper. Stable v1.4.3 package

**UNKNOWN:** execution and control values on the console, full-picture fit,
measured refresh rate and compatibility beyond this setup. Automated
nonblack-pixel detection alone is not a geometry or scan-type proof.
